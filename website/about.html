Why we built PhotoFlow

Studio photography has an unglamorous middle. Between the shoot and the finished album sits an enormous amount of repetitive work: culling thousands of near-identical frames, finding the good ones, working out who is in which photo, and arranging it all onto pages. Meanwhile the counter keeps producing passport photos, ID photos and collages, one at a time, by hand.

Plenty of tools help with parts of that. Very few carry a shoot all the way from raw folder to something you can send to a print lab. PhotoFlow is our attempt at that whole path, in one application, running on the computer that's already in the studio.

How we approach it

Built by watching real work

The passport photo tool exists because we watched a studio do it manually, step by step, and rebuilt those steps. The multi-person sheet exists because wasting a sheet per person is an actual daily annoyance, not a hypothetical one.

Local first

A wedding is private. Processing on your own machine avoids uploading clients' faces to somebody else's servers, and it means the software keeps working when the connection doesn't.

Automatic, never locked

Automation should save time without taking away judgement. Everything PhotoFlow decides can be changed — a crop dragged, a layout swapped, an effect dialled down or switched off.

Honest about limits

Face detection misses people sometimes. Automatic layouts aren't always the choice you'd make. We'd rather say so plainly and give you the controls to fix it than pretend otherwise.

Where we are now

PhotoFlow is in beta and free to use while it is. We're deliberately working with a small number of studios rather than launching loudly, because the feedback from real shoots is what's shaping it. If you run a studio and want to be part of that, we'd like to hear from you.
