System requirements

Operating systemWindows 10 or Windows 11, 64-bit
ProcessorAny modern 64-bit CPU. More cores make batch processing faster.
Memory8 GB minimum, 16 GB recommended for large shoots
Disk spaceAbout 2 GB, including the bundled models
Display1366×768 or larger
InternetNot required. Only used for updates and the first-time model download.

Installing

Run the installer

Double-click the downloaded file and follow the prompts.

If Windows warns you

Early beta builds aren't code-signed yet, so Windows SmartScreen may show a warning. Choose More info then Run anyway. Code signing is on our list before the first paid release.

Open PhotoFlow

Pick a mode and start with a small folder to get a feel for it.

Other platforms

PhotoFlow is Windows-only today, because that's what the studios we work with use. If you need macOS or Linux, tell us — demand is how we decide what to build next.
