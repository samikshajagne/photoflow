# PhotoFlow runtime dependencies.
#
# - PyYAML: config loading (utils/config.py).
# - Pillow + ImageHash: image loading and perceptual hashing
#   (core/duplicate_detector.py).
# - OpenCV (headless) + NumPy: blur (Variance-of-Laplacian), brightness/
#   contrast, and face image loading (core/blur_detector.py,
#   core/quality_scorer.py, core/face_detector.py). Headless because
#   PhotoFlow needs no GUI windowing.
# - MediaPipe: face detection (core/face_detector.py).
# - InsightFace + onnxruntime: face embeddings for person/identity clustering
#   (core/insightface_backend.py, used by the album orchestrator). Required for
#   person-aware albums; the feature degrades gracefully if absent.
# - psd-tools: write layered .psd album spreads directly (core/album/raster.py),
#   enabling PNG/JPG/PDF/PSD album export with no Photoshop required.
# - PyQt6: the desktop UI (ui_qt/).
# - openai: GPT-4o Vision API for scene understanding (core/vision_brain.py).
# - python-dotenv: loads OPENAI_API_KEY from .env at the project root.
