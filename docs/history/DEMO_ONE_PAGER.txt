QUICK Q&A

Q: How does it compare to Adobe Sensai?
A: Sensai removes bad photos; PhotoFlow removes bad photos AND clusters by
   person AND generates album layouts. Different purposes. We're end-to-end.

Q: Does it work on Mac/Linux?
A: Windows first. Code is OS-agnostic; Mac/Linux Phase 2 priority.

Q: What if I have 10,000 images?
A: MediaPipe + InsightFace handle large batches. Bottleneck is I/O + preview
   rendering. Phase 2 adds lazy loading + batch caching. Target: 10K in ~30 min.

Q: Can I customize templates?
A: Not yet. Phase 3 is the template engine. Roadmap includes community/partner
   template marketplace.

Q: Is the export edit-ready?
A: Yes. PSD includes layers (photos, text, backgrounds, shapes) for tweaking.
   PNG/JPG are rasterized final output.
